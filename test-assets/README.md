# E-Scan benchmark assets

Use synthetic documents, public-domain samples, or documents created specifically for testing.

Do not commit real identity documents, medical records, bank statements, private contracts, or any other personal/confidential documents.

For each fixture, record:
- Source and license
- Expected page boundary or corner coordinates
- Document language(s)
- Capture conditions
- Expected OCR text only when legally and safely distributable
- Known limitations

Keep the same source fixtures for Android and Web comparisons.
